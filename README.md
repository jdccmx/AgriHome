# AgriHome
Repositorio para el desarrollo del proyecto de Innovación 2026, AgriHome. Cultivos domésticos inteligentes aplicando programación avanzada.

En este repositorio, se contienen los siguientes archivos correspondientes a la etapa 2 del desarrollo del proyecto:
- main.cpp. Archivo del código C++ completo usado para programar el microcontrolador ESP32-S3, el cual realiza el procesamiento del sistema de cultivos inteligentes, tomando en cuenta las mediciones de los sensores para activar/desactivar los actuadores que conforman el sistema.
- Graficas.py. Archivo del código Python que se emplea para generar visualizaciones de las mediciones de los sensores. El programa genera un archivo CSV en donde se registran las mediciones de cada uno de los sensores junto con timestamp. De igual forma, se generan gráficas con estos datos en una serie de archivos PNG.
- datos_maceta.csv. Archivo CSV generado por el programa Python. Registro de mediciones de los sensores que conforman el sistema de AgriHome.
- U3A2_Etapa2_CastruitaDavid.pdf. Documento PDF donde se presentan los avances realizados en esta segunda etapa del desarrollo del proyecto. Aquí se proporciona una explicación más detallada de los avances del proyecto, incluyendo diagramas, imágenes y tablas descriptivas.
